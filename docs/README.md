# Documentation

This folder contains all Springwell-Keel documentation.

## Architecture Decision Records (ADRs)

ADRs are how we document significant design decisions — what we decided, why, and what we explicitly left open. Every major architectural choice should have one.

Current ADRs:
- [ADR-001: Three-Lane Architecture](adr/ADR-001-three-lane-architecture.md)

If you disagree with an ADR, open an issue. That's the point.
